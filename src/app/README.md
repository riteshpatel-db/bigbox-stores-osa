# bigbox-ops-app

AppKit (TypeScript / React) app for the Director of Operations of Bigbox Stores. Deployed by the
repository's bundle (`../resources/bigbox_ops_app.app.yml`); see the repository README, section
"App (stage F)", for what it does, its identity model and how it is deployed and smoke-tested.

| Path                                 | Contents                                                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `server/server.ts`                   | AppKit plugins: analytics, genie, lakebase, server, serving                                                            |
| `server/routes/ops.ts`               | `/api/health`, `/api/whoami`, `/api/snapshot`, `/api/queue`, `/api/items/:store/:sku`, `/api/whatif`, `/api/decisions` |
| `config/queries/`                    | KPI header SQL on the metric views (run as the app's service principal)                                                |
| `client/src/pages/`                  | `ops/OpsPage.tsx` (KPI header, queue, item detail), `genie/GeniePage.tsx` (embedded Genie)                             |
| `client/src/components/`             | `KpiHeader`, `Queue`, `ItemSheet` (what-if and decision form)                                                          |
| `client/src/lib/api.ts`              | Typed (zod) calls to the server routes                                                                                 |
| `shared/appkit-types/analytics.d.ts` | Query result types generated by `npm run typegen`                                                                      |

Checks: `npm run typecheck && npm run lint && npm run lint:ast-grep && npm run format`.

Local development needs the app deployed first (its service principal owns nothing, but the
Postgres grants are made for it) and a `.env` from `.env.example`; then `npm run dev`.
